# Messenger17

Готовая автономная версия премиального мессенджера без Supabase и без настройки.

Открываешь `index.html` — и приложение работает сразу.

## Что есть

- Регистрация и вход локально в браузере.
- Профиль пользователя.
- Поиск пользователей.
- Заявки в друзья по согласию.
- Принятие/отклонение заявок.
- Личные чаты после принятия заявки.
- Сообщения.
- Группы.
- Каналы.
- Новости.
- Настройки и темы.
- Адаптив под ПК и телефоны.

## Важно

Эта версия работает без сервера: данные хранятся в `localStorage` конкретного браузера.
Для настоящего онлайн-мессенджера между разными устройствами нужен backend/хостинг.
